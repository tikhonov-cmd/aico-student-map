# AICO — студенческий сайт

Опубликован: https://tikhonov-cmd.github.io/aico-student-map/

Три страницы: `index.html` — главная, `route.html` — маршрут, `method.html` — метод исследования.
Статический сайт без сборки. Общие стили — `student.css`; интерактивные примеры — `product-demo.js`; оглавление метода — `method.js`.

GitHub Pages публикует корень ветки `main`. После изменения CSS и JS обновляйте хеши `?v=` в HTML.

Локальный запуск: `python3 -m http.server 4173` из этой папки.

Исходная студенческая версия перенесена из `aico-teacher-map/students`. Дальнейшие правки студенческого сайта следует делать в этом репозитории.

## Версии

Новая памятка опубликована на основном адресе. Предыдущая версия сохранена целиком в `previous/`: https://tikhonov-cmd.github.io/aico-student-map/previous/ . Это снимок коммита `fcea0d4`, сделанный до переработки 21 сентября 2026 года; её HTML, стили, скрипты и шрифты независимы от новой версии. Для возврата можно восстановить корневые файлы из этого коммита либо скопировать содержимое `previous/` в корень.

Главная ведёт от приглашения к условиям и ближайшим шагам. Анимация сохранена ниже, учебный пример раскрывается по желанию. Сроки и состав этапов зависят от курса; ссылки на анкеты студент получает в сообщении команды.
