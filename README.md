# AICO — студенческий сайт

Опубликован: https://tikhonov-cmd.github.io/aico-student-map/

Три страницы: `index.html` — главная, `route.html` — маршрут, `method.html` — метод исследования.
Статический сайт без сборки. Общие стили — `student.css`; интерактивные примеры — `product-demo.js`; оглавление метода — `method.js`.

GitHub Pages публикует корень ветки `main`. После изменения CSS и JS обновляйте хеши `?v=` в HTML.

Локальный запуск: `python3 -m http.server 4173` из этой папки.

Исходная студенческая версия перенесена из `aico-teacher-map/students`. Дальнейшие правки студенческого сайта следует делать в этом репозитории.
